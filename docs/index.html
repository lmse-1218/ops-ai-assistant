三个界面

安全智能运维平台 —— 统一入口，四个功能面板：漏洞分析、故障排查、配置审计、知识库问答。

浏览器智能助手 —— 粘贴一段网页长文，一键总结 / 解释 / 翻译；也可以直接对内容提问，回答下方列出检索到的参考片段。

ReAct Agent 推理演示 —— 思考 → 行动 → 观察的循环逐步渲染。
这一例值得说明：第一轮工具调用没有命中，Agent 在 Observation 之后自己判断出原因（工具依赖关键词字面匹配，而原始问法里没有出现「SQL注入」这类词），于是改写参数重试，第二轮拿到了完整漏洞报告（CVSS 9.8 / CWE-89 / OWASP A03 / 修复建议）。

做了什么

  • 检索层用双路召回再融合。向量检索擅长语义相近，BM25 擅长精确关键词（OR 1=1、UNION SELECT 这类 payload 向量反而不敏感），只用一路都会漏；两路结果用 RRF 倒数排名融合，避免单一分数量纲不一致的问题。
  • Agent 用显式 ReAct 循环，而不是一次问答。每一轮的思考、动作、观察都渲染在页面上，最多 5 步。好处是失败可归因——上面那张截图里第一轮为什么没命中，页面上直接看得到。
  • 宁可不答，也不编。当检索到的片段只覆盖攻击原理、没有防护方法时，直接说明「参考资料中没有提供」，而不是补一段模型自己的常识。测试时就遇到过：问「SQL 注入怎么防御」被拒答，检查后发现知识库里那几条确实只写了识别特征。
  • 没有 API Key 也能启动。内置 Mock 模式，克隆下来直接 uvicorn 就能看到界面和交互，降低复现门槛。

uvicorn group_project:app --reload --port 8002
